## Interpretation and parameter availability

The joint trend experiment is mixed. Per-prediction pooled green finish MAE
improves 14.759 -> 14.047 s, while bias worsens -2.343 -> -6.635 s and
coverage falls 37.9% -> 36.5%. Equal-race finish MAE improves
14.597 -> 13.750 s. Pooled 10-lap MAE worsens 3.961 -> 3.994 s and
coverage falls 52.3% -> 49.9%.

Bahrain with-stop finish bias improves +12.899 -> +2.007 s, but no-stop
finish error/lap worsens -0.278 -> -0.649. Spain with-stop finish bias
worsens -10.588 -> -11.030 s and no-stop finish error/lap worsens
-0.762 -> -0.809. Spain SOFT no-stop finish error/lap changes only
-1.067 -> -1.057; it remains substantially too fast. France's 10-lap bias
is small (+0.014 s/lap), with worse MAE. Thus a fitted trend has not solved
the clean pace/wear problem, even though it reduces Bahrain's stop-containing
overshoot. All compound/age comparisons above use matched cohorts.

Different stint start laps can identify a trend statistically, but the regression
can still confound driver management, race evolution, fixed offset error and
nonlinear wear. One linear trend is extrapolated beyond the cutoff. No result
was used to change priors, eligibility, shrinkage or interval sizing.
